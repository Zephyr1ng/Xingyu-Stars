# 星宇之境 · Universe of 星宇 ✨

一个纯 HTML 的照片星辰盲盒。每张照片藏在夜空中的一颗五角星里，鼠标悬停 → 五角星形照片预览，点击 → 放大观赏。

背景是不间断的紫色流星雨，并针对移动端和“减少动态效果”偏好降低动画负载。

## 使用方法

1. **双击 `index.html`**
2. 点击右上角 **✨ 上传** 或直接把照片拖进窗口
3. 每张照片变成夜空中一颗闪烁旋转的紫色五角星
4. **鼠标悬停在星星上 → 显示五角星形的照片预览**
5. **点击或聚焦星星 → 放大到全屏查看**（左右方向键切换，Esc 关闭）

## 视觉与交互

- **持续流星雨**：从右上方 135° 方向，白/紫/粉三种色调随机穿越，带渐变尾迹和随机流星群
- **多层深空**：极光光晕 + 2 层视差星星（共 130 颗）
- **鼠标视差**：鼠标移动时星空缓慢反向偏移
- **鼠标光尘**：鼠标划过留下淡紫色微光颗粒
- **照片星星**（数据里的）：
  - 真正的五角星形状（SVG clip-path），紫粉渐变，自转 + 呼吸 + 光晕脉冲 + 表面闪烁点
  - 根据可用空间自动分页，以随机化网格避免星星点击区域重叠
- **悬停预览**：
  - 五角星形照片（`object-fit: contain`，优先完整展示）+ 旋转彩虹描边 + 高光叠加
  - 弹性缩放展开，鼠标移出自动合拢
- **点击放大**：
  - 全屏 lightbox，彩虹光晕背板，边缘阴影发光
  - 支持左右切换、删除、Esc 关闭

## 使用小贴士

- **照片存在哪里？** 存在当前浏览器站点的 IndexedDB 里，关机、重启和刷新后仍会保留；实际容量取决于浏览器分配的站点存储配额
- **上传限制**：最多保存 200 张照片；单张不超过 25MB，单次上传总量不超过 120MB
- **⚠️ 不要清"网站数据/所有数据"**：会连同照片一起清掉。清常规缓存/历史记录是安全的
- **换设备/换浏览器？** 数据不共享。先在旧设备“导出”，把照片保存下来，再在新设备重新上传
- **批量导出**：支持目录选择的浏览器会直接写入所选目录；其他浏览器可能提示允许多文件下载

## 快捷键

- `Esc`：关闭放大视图
- `← / →`：查看时切换上一张 / 下一张
- `Tab`：在照片星星和灯箱按钮之间移动焦点
